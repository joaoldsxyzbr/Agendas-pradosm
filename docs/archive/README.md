# Arquivo histórico

Os documentos nesta pasta registram decisões e etapas anteriores da migração para JavaScript puro. Foram preservados para rastreabilidade e consulta.

**Não utilize comandos ou caminhos desses documentos como instrução operacional atual.** As referências antigas a `migration/frontend/`, `src/`, `tests/migration/`, `wrangler.migracao.jsonc` e branches temporárias são históricas.

Para instruções atuais, consulte [Arquitetura](../architecture.md), [Documentação](../README.md) e [Release de produção](../operations/production-release.md).
